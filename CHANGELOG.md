## 1.9.0 source release (build 23)

- Live text-size changes scale the Compact HUD's text and layout, main-window health statistics and inherited controls. The main header selects a layout with room for larger reading text.
- The marketing version remains 1.9.0; the build-only helper advances the build number to 23. A serial release controller delegates to the established signed/notarized release lane. Neither helper installs dependencies or writes Git history.
- The build-23 disk image was signed, notarized, stapled and verified for private testing. Those checks apply to that image, not to a rebuild of the released source.

## 1.9.0 — 2026-11-07

The initial private candidate used build 22. Build 23 above adds the text-size correction while preserving this feature scope.

- Guided mock authoring, batch preparation, drift recovery and explicit activation review.
- Immutable artwork and a bundled licensed non-brand icon catalog with manual selection and optional reviewed local suggestions.
- UI-based similar-item text proposals with review before use.
- MCP and CLI response briefs, comparison and run briefs, digest-qualified repeat reads and bounded analysis reuse.
- Opt-in content-free workflow receipts and offline efficiency reporting.
- Deterministic typed calculations for live capture and locally shared saved artifacts.
- Saved-artifact inventory, exact-match search references and single-response briefs.
- Compare once for an ordered pair of saved responses, with local consent and whole-result suppression if either share is revoked.
- Coverage, incomplete bodies and omitted changes remain explicit in analysis results.

Spoken VoiceOver and physical older-supported-OS/model-unavailable acceptance remain pending. See the snapshot validation record for checks performed on this source.
