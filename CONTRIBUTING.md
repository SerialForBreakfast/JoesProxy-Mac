# Project participation

Revision 2026-11-07.

JoesProxy is a maintainer-led public preview. External code contributions and unsolicited pull requests are currently closed. The source is available for inspection, local builds and use under its license.

For a suspected vulnerability, follow [security reporting](SECURITY.md). The [first-run guide](docs/GETTING-STARTED.md) and [privacy guide](docs/PRIVACY.md) explain how to try the app with synthetic data.

The maintainer may open a broader contribution process later. This preview makes no promise about accepting patches, feature requests or response times.
