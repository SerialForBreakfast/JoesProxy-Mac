# JoesProxy releases

JoesProxy is released as source under the [MIT License](../LICENSE). See [Getting started](../docs/GETTING-STARTED.md) to build and run it on your Mac.

This directory contains the [checksum](SHA256SUMS) for the original build-23 disk image, not an installer download. The image itself is attached to the [1.9.0 release](https://github.com/SerialForBreakfast/JoesProxy-Mac/releases/tag/1.9.0). It predates the public repository link updates. Its [verification record](../docs/releases/1.9.0-build23.md) describes exactly what was tested.
