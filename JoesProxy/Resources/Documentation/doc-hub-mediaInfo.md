# Media Info

## Media Info 1 {#p1}

When a session is classified as media, open Media Info from the inspector to inspect images, AVAsset details, HLS or DASH manifests, ad XML, and timed metadata.

## Media Info 2 {#p2}

Manifest tabs surface variants, audio renditions, segments, discontinuities, and ad-related markers when present in the capture.

## Media Info 3 {#p3}

Agent and CLI workflows can start synthetic HLS fixture profiles and redirect a real host path onto them with Map Local fixture redirect. Live presentations support bounded live time shifting: warm DVR begins with deterministic history, while cold DVR grows from the first completed segment. Live time shifting is distinct from Low-Latency HLS (LL-HLS).

## Media Info 4 {#p4}

The virtual domain https://assets.joesproxy.invalid (or *.synthetic.joesproxy.invalid) serves supported synthetic media in-process. A device must route the relevant request through JoesProxy with the required inspection and matcher configuration. Confirm delivery receipts and a sourced target outcome separately; an available origin does not establish either.

## Media Info 5 {#p5}

Some deeper media analysis runs asynchronously and may require approval when started from MCP or the CLI.
