# Captured Sessions

## Overview {#overview}

Captured Sessions is the live traffic workspace. Table shows a chronological list, Explorer groups by host or endpoint, and Timeline surfaces temporal lanes and gaps. The list updates as new traffic arrives.

## Context and limitations {#context}

- Use Table for chronological scanning, Explorer for grouped navigation by host and path, and Timeline for temporal investigation.
- Search and filters narrow the visible working set without deleting recorded traffic.
- Source badges (Mac, Simulator, Device) help separate intentional DUT traffic from ambient Mac traffic.

## Next steps {#steps}

- Switch between Table, Explorer, and Timeline depending on chronology, grouping, or temporal investigation.
- Use filters and Follow Live before clearing traffic so you can isolate the sessions you actually care about.
