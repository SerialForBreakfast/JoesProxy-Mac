# Getting Started

## Getting Started 1 {#p1}

JoesProxy captures HTTP and HTTPS requests routed through the local proxy. For HTTPS bodies and headers to be visible, the JoesProxy Root CA must exist and be trusted on the device making the request.

## Getting Started 2 {#p2}

Use Table for a dense chronological list of captured sessions.

## Getting Started 3 {#p3}

Use Explorer to group traffic by host and path for easier scanning.

## Getting Started 4 {#p4}

Use Timeline when you need temporal lanes, gaps, and findings.

## Getting Started 5 {#p5}

Optionally enable system proxy routing so Simulator and many Mac apps reach JoesProxy without per-app proxy settings.

## Getting Started 6 {#p6}

Use the setup guides below when device traffic is not appearing or HTTPS bodies stay unavailable.
