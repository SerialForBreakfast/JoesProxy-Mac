# Network Throttling & No Caching

## Network Throttling & No Caching 1 {#p1}

Paces proxied HTTP and HTTPS bytes with editable bandwidth and latency presets. It does not simulate packet loss, and it does not affect tunneled opaque TLS or non-HTTP(S) traffic.

## Network Throttling & No Caching 2 {#p2}

Injects no-cache behavior on intercepted traffic globally or for listed domains so clients fetch fresh responses. Tunneled HTTPS pass-through is unaffected.

## Network Throttling & No Caching 3 {#p3}

Enable throttling from the session toolbar or Settings > Throttling. Configure No Caching from Settings when you need to force refresh behavior during debugging.
