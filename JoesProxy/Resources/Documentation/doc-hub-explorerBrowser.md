# Table, Explorer, and Timeline

## Table, Explorer, and Timeline 1 {#p1}

Use Table for row-by-row inspection, Explorer for folder grouping by host or endpoint, and Timeline for temporal lanes, gaps, and findings.

## Table, Explorer, and Timeline 2 {#p2}

By Host rolls traffic under host or domain-family folders. By Endpoint groups by method, host, and normalized path. Dynamic path segments such as numeric IDs are normalized so similar routes group together.

## Table, Explorer, and Timeline 3 {#p3}

Browser mode, grouping, host rollup, and expanded folder IDs are saved across relaunches. Changing grouping rebuilds the tree; invalid expansion IDs are dropped.

## Table, Explorer, and Timeline 4 {#p4}

Classifies sessions into lanes, detects gaps, and surfaces findings. Very large captures may cap visible bars while keeping the full filtered count.

## Table, Explorer, and Timeline 5 {#p5}

For long captures, use Settings > Advanced > Long Capture Storage to bound retained body data. Table and Explorer split width is preserved when switching between those modes.
