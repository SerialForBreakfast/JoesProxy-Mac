# Session Tools

## Session Tools 1 {#p1}

Search, filter, and sort requests across Table, Explorer, and Timeline to narrow the working set quickly.

## Session Tools 2 {#p2}

Save repeatable requests and refresh them later from current sessions without rebuilding the request by hand.

## Session Tools 3 {#p3}

Attach a saved response to a bookmark, override JSON fields with dot paths, and intercept matching traffic for the current proxy session.

## Session Tools 4 {#p4}

Change matching live traffic with Map Local, Block, Map Remote, live rewrite, or fixture redirect. Newest matching enabled rule wins.

## Session Tools 5 {#p5}

Import, export, and atomically activate named packages (.jproxy-effects) containing coordinated local overrides and HLS substitutions with content-addressed assets.

## Session Tools 6 {#p6}

Serve a captured draft, edited inline text, local file, or HLS fixture redirect instead of the upstream response.

## Session Tools 7 {#p7}

Fail matching requests with a synthetic HTTP error or connection drop for dependency-failure testing.

## Session Tools 8 {#p8}

Forward matching requests to a different host, port, or scheme without rebuilding the client.

## Session Tools 9 {#p9}

Shows the selected session's summary, headers, bodies, timing, truncation or tunneling limits, and override attribution.
