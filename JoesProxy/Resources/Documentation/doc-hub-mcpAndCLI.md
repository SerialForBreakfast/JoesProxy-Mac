# MCP And CLI

## MCP And CLI 1 {#p1}

MCP is an optional local agent server. The bundled joesproxyctl CLI drives the same propose/apply workflows for scripting and automation.

## MCP And CLI 2 {#p2}

Start or stop the server, enroll a client, choose Metadata Only or Shareable disclosure, and grant capabilities. Open with Command-Option-M.

## MCP And CLI 3 {#p3}

Sensitive reads and mutations use propose/apply plus in-app approval. Standing grants reduce repeated prompts for unattended CLI work.

## MCP And CLI 4 {#p4}

Automated headless profiling via xcrun xctrace to correlate Time Profiler stack traces, main-thread hangs (>100ms), and memory allocations with live wire waterfalls.

## MCP And CLI 5 {#p5}

Use joesproxyctl sessions search --domain <d> --path <p> --method <m> --json and pipe output directly to jq for fast, machine-readable traffic inspection.

## MCP And CLI 6 {#p6}

Disable rules, stop fixture runs, and clear scenarios before ending an agent session so live traffic returns to normal.

## MCP And CLI 7 {#p7}

Use joesproxyctl doctor, then auth login from a real terminal if credentials are missing.
