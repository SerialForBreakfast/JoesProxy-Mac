Setup & Orientation

Capture your first real request

Start the proxy, route your target application, and verify that traffic appears in the live table. Add HTTPS body decryption or an AI agent after your baseline capture is working.

Step 1

Start the Proxy

Open JoesProxy and select Start Proxy. Confirm the status pill reports Running (default port 9090).

Step 2

Route Your Target

Point your Mac, Simulator, phone, or Docker container to the proxy host and port.

Step 3

Verify First Session

Perform an action in your app and confirm the new request appears in the live capture table.

Step 4

Add HTTPS / AI Agent

Install the root CA when you need decrypted payloads, or enable MCP on port 9091 for AI pairing.

Target Setup Guides

Select your target platform to view verified routing instructions.

Routing macOS Traffic

To capture traffic from browsers and Mac applications, turn on macOS system proxy routing:

  1. In JoesProxy, click Start Proxy.
  2. Enable Set macOS System Proxy in the top toolbar, or use the menu bar extra popover.
  3. Open Safari or run a curl request in Terminal. Your requests will appear live in the table.

iOS Simulator Setup

The iOS Simulator automatically shares your Mac’s system proxy settings when system proxy is enabled.

  1. Open Certificate > HTTPS Setup in JoesProxy.
  2. Select Simulator Setup to view all booted simulators and install the JoesProxy root CA with one click.
  3. Launch your app in the Simulator. Decrypted HTTPS sessions will appear in JoesProxy.

iPhone & iPad Setup

  1. Ensure your iPhone/iPad is on the same local Wi-Fi network as your Mac.
  2. In iOS Settings > Wi-Fi, tap the info icon next to your network, scroll to Configure Proxy, choose Manual, and enter your Mac’s local IP address and port 9090.
  3. Open Certificate > HTTPS Setup in JoesProxy to scan the QR code or AirDrop the root certificate profile to your device.
  4. In iOS, go to Settings > General > VPN & Device Management to install the profile, then go to Settings > General > About > Certificate Trust Settings to enable full trust.

Apple TV (tvOS) Setup

Apple TV requires a supervised configuration profile to install custom root certificates.

  1. Open Help > Apple TV Setup Guide in JoesProxy.
  2. Export the payload profile or install it via Apple Configurator / MDM.
  3. Set HTTP proxy on Apple TV Wi-Fi settings to point to your Mac.

Docker Container Egress Setup

Export the root CA and pass standard proxy environment variables to your container: 

# 1. Export JoesProxy root CA certificate
joesproxyctl certificate export --format pem --output ./joesproxy-ca.pem

# 2. Run container with HTTP/HTTPS proxy pointing to host
docker run -e HTTP_PROXY="http://host.docker.internal:9090" \
           -e HTTPS_PROXY="http://host.docker.internal:9090" \
           -e SSL_CERT_FILE="/certs/joesproxy-ca.pem" \
           -v "$(pwd)/joesproxy-ca.pem:/certs/joesproxy-ca.pem" \
           my-app-image

AI Coding Assistant (MCP) Setup

Connect Claude Code, Cursor, or Codex via the Model Context Protocol:

  1. In JoesProxy, open MCP > Open MCP Management (⌘⌥M) and click Start MCP Server (default port 9091).
  2. Configure your agent client to connect to http://127.0.0.1:9091/mcp.
  3. Verify connectivity by running joesproxyctl doctor in terminal.
  4. Prompt your agent in natural language to inspect traffic or propose mutation rules.

Troubleshooting: What to check if no traffic appears

  • Proxy listener state: Confirm the status indicator in JoesProxy reports Running on port 9090.
  • Network reachability: If debugging a physical device, confirm device and Mac are on the same Wi-Fi subnet with AP isolation disabled.
  • Target bypass list: Verify that target domains are not included in macOS Network Proxy Bypass / Exception lists.
