Return to Normal: Restoring Default Network State

When your debugging or testing session is complete, JoesProxy makes it easy to restore default network conditions:

  • Select Proxy > Stop Proxy (⌘⌥.) to stop the proxy and restore macOS system network settings.
  • Use the Disable All Overrides button in the toolbar to clear active Map Local, Block, and rewrite rules.
  • Quit JoesProxy cleanly; all system proxy routing is automatically deactivated upon application exit.
