# JoesProxy 1.9.1 (25) candidate notes

Prepared November 13, 2026. This candidate extends the [build 24 feature set](1.9.1-build24.md) with clearer tool discovery for status histograms, JSON comparison fixes that preserve Boolean and string distinctions, and loopback routing hardening.

### What changed for agents

An agent investigating a time window can ask how many requests returned each HTTP status, including missing responses. The search and list descriptions point to the calculation tool. Its schema explains how to select the root metadata rows. The Mac can return the groups in one call, with coverage information for the agent to inspect.

On a synthetic 400-request window, Flash Low chose the calculation first and returned the exact six counts in five of five autonomous trials. Four used one MCP call. Public 1.9.0 answered exactly in three of five trials. For the three pairs where both answers were correct, build 25 used a median 65.2% fewer reported total tokens. The [versioned benchmark report](benchmarks/1.9.1-edge-v7.md) includes all ten attempts, tool choices, ranges and the guided comparison.

The release branch also contains a November 14 wording update to the portable skill and its app export source. The signed installer and the reported trials predate that documentation update.

### Other changes since 1.9.0

- Filter retained metadata by method, disclosed domain or path, and inclusive timestamps. Search for an example or group a page by endpoint after examining the totals.
- Inspect selected JSON fields and compare bounded value changes. Comparison briefs distinguish a JSON Boolean from a string such as `"true"`.
- Inspect rule near misses, credential continuity and capture omissions. Local review governs routing to a loopback development server.
