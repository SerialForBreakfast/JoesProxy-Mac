## JoesProxy 1.8.1

Revision: 2026-09-23. **1.8.1 (build 18)** delivers guided, repeatable multi-resource experiments
and capture-recovery improvements. The local universal DMG is signed, notarized, stapled and
independently verified. The maintainer confirmed 1.8.1 is released. The next planned release is
1.8.2; its five implementation tranches and acceptance boundaries are tracked in [public snapshot notes](../PUBLIC-SNAPSHOT.md).

- **Guided mocks:** prepare immutable JSON and multiple-image revisions, related endpoints and
  bounded live collection edits with explicit client scope and separate activation review.
- **Repeatable experiments:** reviewed phases, timestamp bindings and explicit baseline/run
  windows, with shared delivery evidence, comparisons and cleanup across the app, MCP and CLI.
- **Queryable documentation:** shared Markdown Help with offline CLI and connected MCP search
  and section retrieval. Documentation reads need no capture or mutation authority.
- **Media diagnostics:** multilingual WebVTT fixtures, compatible prepared HLS transitions and
  caption delivery attribution, kept distinct from player-rendering confirmation.
- **Capture recovery:** distinguish oversized requests from overload, freeze admitted body
  limits, release reservations on terminal paths and expose bounded recovery/stall diagnostics.

Capture completeness is separate from forwarding. Body limits, retention and overload can leave
prefix-only bodies or evidence gaps. Full-body unlimited response capture is not included.
Long-duration idle/drain and broader UI/device validation are deferred with recorded limitations.
No leak-free, unlimited capture, or 24-hour stability claim is made.

manual-install; automatic updates and remote release publication are not part of this package.
