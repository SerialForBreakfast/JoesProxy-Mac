# JoesProxy 1.9.1 benchmark report, revision 2

## November 13, 2026 — optimized 60-minute rehearsal

JoesProxy completed 441 cycles in 3,603.6 seconds. The synthetic origin received 11,278 requests. The origin used port 41000 and the proxy used port 41100. The run recorded zero invariant failures, zero 502 responses and zero upstream self-connect notices. Both status-count workflows returned the correct answer in all 441 paired comparisons. The low-port result supports the port-collision hypothesis. The cause of the earlier intermittent 502s remains unconfirmed.

| Status-count workflow on this Mac | Median RPC bytes | Median workflow latency |
|---|---:|---:|
| Page through search results and calculate by ID | 8,834 | 37.3 ms |
| Filter and calculate locally | 1,315 | 11.7 ms |

The local calculation used 85.1% fewer median RPC bytes for this question. In the separate concurrent live-query exercise, 1,574 attempts succeeded and 190 returned `source_changed` as capture advanced. Those outcomes need to be counted when measuring end-to-end agent usage.

These measurements describe the optimized development checkout used for the rehearsal. The next eight-hour soak is deferred.

## November 13, 2026 — subscription-token experiment (revision 2)

For a 300-request window, Flash Low used **62.2% fewer reported total tokens** to count status codes with build 25. This is the median within-pair reduction across the four pairs where both versions produced a correct answer and completed the recorded MCP workflow. Asking for one inspected example reduced tokens by **54.0%** across three qualifying pairs.

| Frozen question | Correct answer and exact MCP sequence, 1.9.0 → build 25 | MCP calls in a complete workflow | All five attempts, median total tokens [min–max], 1.9.0 | Build 25 | Median paired reduction [eligible pairs] |
|---|---:|---:|---:|---:|---:|
| Count 502s and missing statuses | 4/5 → 5/5 | 3 → 1 | 50,821 [21,415–50,864] | 19,231 [19,224–19,239] | 62.2% [4] |
| Count and inspect one 502 | 3/5 → 5/5 | 4 → 3 | 53,719 [23,478–55,927] | 24,753 [24,751–27,151] | 54.0% [3] |
| Identify the functional JSON change | 5/5 → 3/5 | 2 → 1 | 22,272 [20,224–22,275] | 19,871 [19,866–19,876] | 10.8% [3] |

**Method.** Five pairs per question, alternating which version ran first. Every attempt started a fresh AGY 1.3.1 conversation with the signed-in subscription, model `gemini-3.8-flash-low`. Each arm used synthetic responses recorded by its own JoesProxy app-hosted MCP integration test. A local replay server verified tool name, arguments, order and completion. The prompt supplied the workflow and exposed its tools. This measures guided agent execution; autonomous discovery requires a separate experiment. The previous release used its 100-row page limit and reused a returned ID for the example. Both arms had equivalent disclosure permissions. The grading key was kept outside the prompt.

**Grading.** The count had to match 299 status-502 responses and one missing status. The example also needed a verified request ID, status and path. For the comparison we accepted equivalent field paths and an explicit indication of complete coverage. The frozen oracle requires Boolean values. Two build-25 answers correctly named the change but returned the strings `"false"` and `"true"`. They failed the typed-answer check. Three old-version count/example attempts failed to complete the exact replay sequence and returned wrong or incomplete answers. All five attempts per arm contribute to the displayed token distributions. Only pairs where both arms passed contribute to paired savings.

**Accounting.** The 30 measured attempts used 866,252 AGY-reported total tokens. Per-attempt input, output, thinking and cache-read counters are preserved as returned. Cache-read counts can exceed reported input and are not added to AGY's total. Setup probes are excluded. Sample sizes are small, and repeated prefixes may benefit from provider caching. Results apply to this model, prompt, client and workload. The workload-specific 85.1% figure above measures RPC bytes in the separate hour-long rehearsal.
