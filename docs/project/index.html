Open Source Project

Built for developers and AI coding agents

JoesProxy was created to provide a lean, transparent, and scriptable alternative to commercial proxy tools, with first-class support for AI agent collaboration.

Core Principles

The non-negotiable architectural tenets that guide JoesProxy development.

Local-First Privacy

Capture processing is local, with no application telemetry. You control exports and agent disclosure; independently connected clients may process approved evidence through their own services.

Human Agency in AI Loops

AI coding assistants are powerful partners, but they should never modify network behavior invisibly. Every agent proposal requires explicit human approval in the native UI.

Native macOS Craftsmanship

Built in pure Swift 6 and Apple SwiftNIO without Electron or web wrappers. Fast startup, low CPU usage, and faithful adherence to macOS interaction design.

Contributing & Development

JoesProxy is a maintainer-led source preview. External code contributions are currently closed. The project uses file-system synchronized groups; follow the first-run guide for the existing toolchain and locked dependencies. 

# Clone repository
git clone https://github.com/SerialForBreakfast/JoesProxy-Mac.git
cd JoesProxy-Mac

# Build app target with Xcode
xcodebuild build -scheme JoesProxy -destination "platform=macOS"

# Run unit and policy test suites
xcodebuild test -scheme JoesProxy -testPlan JoesProxy-Policy -destination "platform=macOS" -parallel-testing-enabled NO -disableAutomaticPackageResolution -onlyUsePackageVersionsFromResolvedFile -skipPackageUpdates
