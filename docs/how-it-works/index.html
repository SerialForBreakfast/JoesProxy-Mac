Architecture & Trust

Private by design. Governed by you.

JoesProxy runs 100% locally on your Mac using native Swift and Apple SwiftNIO. No cloud relays, no telemetry, and zero unapproved AI mutations.

Native macOS High-Performance Engine

Engineered for lightweight memory footprints and multi-gigabit loopback throughput.

Swift 6 & Apple SwiftNIO

Non-blocking, event-driven I/O engine built on the same networking stack Apple uses in production. Handles thousands of concurrent connections with minimal CPU usage.

In-Memory Session Store

High-speed circular memory buffers with configurable retention limits (default 250 MB) and periodic background rolling auto-saves to prevent memory bloat during long captures.

Zero Electron / WebKit Bloat

100% native SwiftUI interface. Launches in under a second, consumes negligible idle battery, and adheres strictly to macOS design guidelines.

The Request Journey

How traffic flows through JoesProxy's inspection and mutation pipeline.

Phase 1

Ingress & Decryption

Target client connects via HTTP forward or HTTPS CONNECT. For eligible HTTPS, JoesProxy mints an ephemeral dynamic certificate signed by the local CA.

Phase 2

Rule Evaluation

The rule engine checks Map Local, Block, Map Remote, live rewrites, and semantic vector matchers against the incoming request path and headers.

Phase 3

Upstream Dispatch

If not blocked or locally mapped, the request is dispatched to the upstream destination over TLS with keep-alive connection pooling.

Phase 4

Capture & Delivery

The raw response is captured, optionally patched by active rewrite rules, and streamed back to the client application.

Security Governance

Human-in-the-Loop AI Approvals

JoesProxy is designed with strict capability boundaries to ensure AI coding agents (Claude Code, Cursor, Codex) cannot compromise developer safety or modify live traffic without consent.

  • Capability Isolation: Runtime control, header reading, body reading, and traffic mutations each require independent approvals.
  • Loopback-Only Listener: The MCP server binds exclusively to 127.0.0.1 and never listens on external network interfaces.
  • Single-Use Grants: Approvals are single-use by default; no open-ended wildcard write access is granted to AI models.
  • Automated Cleanup: Test scenarios and diagnostic runs automatically revert mutations when an investigation concludes.

Privacy Commitment

Local processing, deliberate sharing

JoesProxy is a local developer tool, not a cloud service. We believe developer traffic and API payloads are strictly private:

  • Authorized Sharing: Capture processing is local. Enrolled clients may receive approved evidence and process it through their own services; exports may be shared or saved to synchronized folders.
  • Zero Analytics or Telemetry: JoesProxy contains no telemetry trackers, user identifiers, or crash-reporting SDKs.
  • Local Certificate Authority: Your root CA key is generated locally on your Mac and stored in your secure macOS Keychain.
  • Auditability: The complete source code is open source and available for independent inspection on GitHub.
