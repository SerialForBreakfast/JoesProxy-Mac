Get JoesProxy for Mac

JoesProxy is free software released under the MIT License. Build it from source on your Mac.

Build from source View on GitHub

Requires macOS 15.1 or later.

Installation Instructions

  1. For a source build, follow the build guide above. If you have a release disk image, verify its checksum before installing.
  2. Double-click the .dmg to open the installer window.
  3. Drag JoesProxy.app into your /Applications folder.
  4. Launch JoesProxy from Applications or Spotlight.

System Requirements

  • Operating System: macOS 15.1 or later.
  • Architecture: Apple Silicon (M1/M2/M3/M4) & Intel 64-bit.
  • Dependencies: None (zero Java, Node.js, or Python runtimes required).
